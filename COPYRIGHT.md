## What this file is

This file is a copyright notice and a contact for takedown notices. Copyright
in the work exists when the work is fixed. This file records the claim and

## What this file is not

This file is not a registration certificate. Registration is a filing with
the United States Copyright Office at https://www.copyright.gov/registration/.
There is no registry called “the DMCA” to enroll a work in.

The Digital Millennium Copyright Act is the United States procedure a copyright
owner uses to ask a host to take down a specific unauthorized copy. A notice
has to identify the work and the URL of the copy. A blanket strike, with no
infringing URL, is not a DMCA notice.

Send the URL of a commercial or redistributed copy to youshould@getacustom.one
and the owner can send the host a takedown notice for that URL.
